## 任務二：YOLO 靜態圖片測試

對應第一節後半：[01-lab1.md](01-lab1.md)

### 要做什麼

1. 先跑內附圖片：

   ```bat
   python labs\lab1_detect.py --source data\samples --headless
   ```

2. 拍一張自己的照片，裡面同時放**瓶子**和**鉛筆**，存到 `data\mine\`。
3. 執行：

   ```bat
   python labs\lab1_detect.py --source data\mine
   python labs\lab1_detect.py --source data\mine --conf 0.05
   ```

### 留下什麼

- 標註後的圖片
- `index.jsonl` 裡對應的那一行
- 兩次 `--conf` 不同時，結果有什麼差別

### 想一想

- 瓶子的類別名稱與分數是多少？
- 鉛筆有被認出來嗎？
- 為什麼把 `--conf` 調低，仍然不一定能讓模型認出鉛筆？
- 如果你真的想讓模型認鉛筆，需要做什麼？

## 任務三：比較不同 `--every`

### 要做什麼

用同一個影片跑三次，只改 `--every`：

```bat
python labs\lab2_loop.py --source data\samples\test.mp4 --every 1  --loop --headless --max-frames 60
python labs\lab2_loop.py --source data\samples\test.mp4 --every 5  --loop --headless --max-frames 60
```

| 1 | | | | | |
| 5 | | | | | |
| 20 | | | | | |

### 想一想

- 為什麼「跳過幀」不是 bug？

對應第二節後半：[04-lab4.md](04-lab4.md)

### 要做什麼

分別跑三種來源：

## 加分挑戰

這些不用全做，挑你有興趣的：

1. 換一顆真的認得你目標物的權重，然後用 `--weights models\best.pt` 跑同一支程式。
2. 寫一支 `report.py` 讀 `index.jsonl`，輸出總共有幾張、最高分是哪張、每個類別出現幾次。
3. 替 `lab4_patrol.py` 加上 `--summary-json`，把摘要也存成 json。
4. 改善飛行安全，例如加一個「幾秒沒收到按鍵就自動懸停」的保護。
