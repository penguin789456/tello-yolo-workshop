## 3. 兩種控制方式差在哪（這章的重點）

### 路徑控制：指令會「等它做完」

```python
tello.move_forward(100)      # 這一行會卡住，直到飛機真的飛完 1 公尺
```

`move_forward` 是**阻塞**的：djitellopy 送出指令後會等飛機回 `ok` 才返回。所以

- 程式跑完這一行，動作就是真的做完了 —— **不需要自己算時間、不需要 `sleep`**
- 但飛行途中程式什麼都不能做：不能看畫面、不能回應按鍵

**適合**：可重複的固定動作、自動巡檢路線、要寫成腳本的流程。

### 手動操控：指令是「持續的速度」

```python
tello.send_rc_control(lr, fb, ud, yaw)   # 送出就返回，不等
```

`send_rc_control` 是**不阻塞**的：送出去就回來，飛機照著那組速度一直飛，直到你送
新的一組。所以

- 主迴圈必須**持續送**，而且要節流到 20 Hz 以內（程式裡是每 50 ms 一次）
- 你不送，它就照最後一筆速度繼續飄 —— 這就是「放開不會停」的原因

```python
RC_INTERVAL_S = 0.05        # 每 50 ms 送一次 = 20 Hz
```

**為什麼要節流？** Tello SDK 建議 rc 指令不要超過 20 Hz。灌太快會塞爆指令通道，
反而讓起飛／降落這類**需要回應**的指令被拖延 —— 實測灌到 125 Hz 就會出現這個現象。
主迴圈本身跑得比 20 Hz 快得多，所以一定要自己擋。

### 一張表

| | 路徑控制 | 手動操控 |
|---|---|---|
| 指令 | `move_forward(100)` | `send_rc_control(0, 40, 0, 0)` |
| 會不會等 | **會**，等飛完才返回 | 不會，送出就返回 |
| 要不要重複送 | 不用，一次就好 | **要**，每 50 ms 一次 |
| 不送會怎樣 | — | 照最後一筆速度繼續飛 |
| 飛行中能做別的事嗎 | 不能 | 可以（看畫面、收鍵盤） |

**lab3 會用手動操控**，因為那支要邊飛邊看畫面。

## 4. 程式碼導讀

### 鍵盤：沒有視窗怎麼收按鍵

lab2 和 lab3 有影像視窗，可以用 `cv2.waitKey` 收鍵盤。這一支沒有視窗，所以改用
`msvcrt`：

```python
import msvcrt

if not msvcrt.kbhit():       # 先問「有沒有人按」
    return None
ch = msvcrt.getch()          # 有才讀走
```

**先問再讀**是關鍵：`getch()` 自己會卡住等人按鍵，那樣主迴圈就沒辦法每 50 ms
送一次 rc 指令了。

> **`msvcrt` 是 Windows 專用。** 非 Windows 的話這一支的 `--manual` 跑不起來
> （`--path` 沒問題，它不收鍵盤）。想在 macOS / Linux 練手動操控，用 lab3 ——
> 它有影像視窗，走 `cv2.waitKeyEx`，跨平台。

### 安全：三道閘門

```python
MIN_BATTERY_PCT = 30
```

1. **預設不起飛。** 不加旗標就只連線印狀態。
2. **電量低於 30% 不起飛**，並且告訴你現在幾 %。Tello 自己大約 10~20% 才會拒絕，
   但那時候飛行已經不穩了，不如早點擋下來。
3. **`finally` 一定收乾淨**：rc 歸零 → 還在飛就降落 → `end()`。不管是正常跑完、
   按 `Q`、`Ctrl-C` 還是程式炸掉，都會走到。

```python
finally:
    close_tello(tello, land_first=flying)
```

**CLI 程式一結束就沒人控制飛機了**，所以預設會降落 —— 懸停到電池耗盡然後掉下來
更糟。

### 失敗了也要降落

```python
except Exception as exc:
    print(f"  前進失敗：{exc}，直接降落")
    return False
```

前進指令失敗**不代表飛機在地上**。它還在空中，所以回傳 `False` 讓主迴圈的
`finally` 去降落。**出錯的時候才最需要收尾。**

## 6. 常見錯誤

| 訊息／現象 | 原因 |
|---|---|
| `連不上 Tello`（等約 28 秒） | Wi-Fi 沒連到熱點，或上一個 python 還開著占住 UDP 8889。**那 28 秒是重試，不是當掉** |
| `--distance 必須在 20~500 之間` | Tello SDK 的限制。程式在連線前就擋下來了 |
| `電量只有 N%，低於 30% 不起飛` | 換電池 |
| `起飛失敗：...` | 後面會印電量與溫度。多半是電量低或機身過熱 |
| 飛機一直往前飛停不下來 | **按空白鍵。** 手動模式的速度會 latch 住 |
| `--manual` 報 `ModuleNotFoundError: msvcrt` | 你不在 Windows。`--path` 可以用，手動操控請改用 lab3 |
