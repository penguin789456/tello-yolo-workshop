# 三支程式差在哪

三支範例各自完整、不共用任何模組，所以「看得出全貌」這件事由這份文件負責。

想自己對照就用 `fc`（Windows 的 diff）：

```bat
fc labs\lab1_flight.py  labs\lab2_capture.py
fc labs\lab2_capture.py labs\lab3_detect.py
```

## lab1 → lab2：把影像接進來

**新增**

- `streamon()` 與 `get_frame_read()`
- `read_frame()`：讀最新一格、**RGB 轉 BGR**、用字串 `"wait"` 表示「還沒吐出第一格」
- `FIRST_FRAME_TIMEOUT_S = 10.0`：等不到畫面就放棄並說明原因
- `draw_status()`：狀態列畫在畫面下緣
- `open_run()` / `save()`：`runs\<時間戳>\` + `index.jsonl`
- `cv2.imshow` + `cv2.waitKey` 的主迴圈
- `--source video`：沒有無人機時的練習來源

**拿掉**

- **所有飛行指令**。按 `T` 只會印一行提示叫你去用 lab1
- `msvcrt`（有視窗了，改用 `cv2.waitKey`）
- 電量檢查（不會飛，就不需要）

**為什麼拿掉飛行**：一次只練一件事。畫面卡住的時候，如果同時在飛，你分不清是串流
的問題還是飛機在飄。

## lab2 → lab3：加上操控與辨識

**新增**

- 段落 2 `load_model()`：**在主迴圈開始前**載好 YOLO 並 warmup
  （實測 3 秒 —— 不能等按下 `P` 才載）
- 段落 4 `detect()`：對一張影像跑 YOLO，回傳 `Detection` 串列與延遲
- 段落 5 `draw()`：畫框，**回傳新影像、不修改輸入**
- `snap()`：按 `P` 做的三件事 —— 辨識 → 畫框 → 存檔
- 飛行鍵：`T` / `L` / 空白 / 方向鍵 / `W S A D` / `X`
- **rc 節流**（`RC_INTERVAL_S = 0.05`）
- 三條安全規則：起飛前要有畫面、降落與離開分開、`finally` 一定收乾淨
- `--no-model`：不載模型，`P` 只拍照（等同 lab2 的行為）
- `--snap-every`：自動觸發拍照辨識，給 `--headless` 自動測試用

**改寫**

- `index.jsonl` 的 `count` / `classes` / `latency_ms` 現在真的有值了
  （lab2 的欄位形狀一樣，只是都是空的 —— 這是刻意的，方便對照）
- `cv2.waitKey` → `cv2.waitKeyEx`（要吃方向鍵，`waitKey` 只回低位元組）

**沒有加的東西**（這點和一般教材不一樣，值得注意）

- 沒有 `--every N`（連續辨識的頻率）
- 沒有 `--threshold`（自動存檔門檻）
- 沒有 `--cooldown`（自動存檔冷卻）

因為**辨識只在按 `P` 的時候做**，上面三個參數都不需要存在。
「把『什麼時候做』交給使用者，程式就少掉一整組參數」—— 見
[03-lab3.md](03-lab3.md) 第 1 節。

## 重複了什麼（以及為什麼可以接受）

這幾段在多支檔案裡各有一份，內容幾乎一樣：

| 重複的東西 | 出現在 | 行數 |
|---|---|---|
| 編碼處理 + Python 版本檢查 | 三支 | ~18 |
| `open_source()` 的 Tello 連線與錯誤訊息 | 三支 | ~15 |
| `draw_status()` | lab2、lab3 | ~6 |
| `open_run()` / `save()` | lab2、lab3 | ~30 |

加起來每支檔案約 40~60 行是重複的。**這是刻意的。**

抽成一個 `common.py` 之類的共用模組，換來的是：學生讀 `lab3_detect.py` 時，看到
`from common import save` 就得跳到另一個檔案，而那個檔案裡又有為了三支通用而多出來
的參數與分支。**教材的第一要務是可讀，不是 DRY。**

那什麼時候該抽？當你要改一個共同行為、而且得改三次的時候。那個痛點是真的，但它屬於
「維護一個長期專案」的課，不屬於兩節課的工作坊。

> 業界常見的判斷標準是「重複三次才抽」（rule of three）。我們這裡剛好是三次還不抽，
> 因為讀者是第一次看這段程式的人 —— **抽象的成本由讀者付，不是由作者付。**
