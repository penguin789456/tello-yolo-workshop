# 課程地圖

這份教材分成兩節實作課。第一節先確認兩件基礎能力：**Tello 能不能連上並拍照**、
**YOLO 能不能在本機跑辨識**。第二節把這兩件事合併，做出可以讀即時影像、辨識、
拍照與存檔的整合流程。

你不需要先懂深度學習理論。這門課的目標是看懂一條影像辨識專案的基本管線：

```text
影像來源 → YOLO 推論 → 畫框 → 存圖 → 寫入 index.jsonl
```

---

## 兩節課總覽

| 節次 | 主題 | 本節完成 |
|---|---|---|
| 第一節 | Tello 連線拍照 + YOLO 測試 | 看得到無人機畫面、按 `P` 存圖、用圖片跑 YOLO |
| 第二節 | 拍照與辨識整合 | 用即時影像做辨識，理解 `--every`、門檻、冷卻與整合版工具 |

程式檔案的編號不是上課順序，而是功能累積順序：

```text
lab1_detect  靜態圖片辨識
lab2_loop    連續影像辨識
lab3_tello   Tello 連線、預覽、拍照
lab4_patrol  整合 image / video / tello 三種來源
```

所以第一節會先用 `lab3_tello.py`，再回頭用 `lab1_detect.py` 測試 YOLO。第二節再看
`lab2_loop.py` 和 `lab4_patrol.py` 怎麼把這些能力接起來。

## 課前一定要做

### 1. 安裝 Python 與套件

```bat
python -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```

`requirements.txt` 會安裝 Tello 連線、OpenCV 與 YOLO 需要的套件。套件下載比較久，
請先裝好，不要留到上課才下載。

### 2. 放好 YOLO 權重

```bat
python -c "from ultralytics import YOLO; YOLO('yolo11n.pt')"
move yolo11n.pt models\
```

### 3. 記住 Tello Wi-Fi 的限制

Tello 會自己開一個 `TELLO-XXXXXX` 熱點。電腦連上它之後，通常會顯示「無網際網路」，
這是正常的。

重要的是：**連上 Tello 後就不能下載套件或權重。** 所以請先在一般網路下把環境裝好，
再切到 Tello 熱點。

## 第一節：Tello 連線拍照 + YOLO 測試

### 目標

- 連到 Tello 的 Wi-Fi
- 用 `--preview-only` 看到無人機畫面
- 按 `P` 拍照並檢查 `runs\<時間戳>\`
- 用 `lab1_detect.py` 跑一次 YOLO 圖片辨識
- 知道 COCO 預訓練權重認得什麼、不認得什麼

### 建議流程

| 順序 | 做什麼 | 指令 |
|---|---|---|
| 1 | 確認基本流程可以啟動 | `python labs\lab4_patrol.py --source image --path data\samples --dry-run --headless` |
| 2 | 連到 Tello 熱點 | 手動切 Wi-Fi 到 `TELLO-XXXXXX` |
| 3 | 看無人機畫面 | `python labs\lab3_tello.py --preview-only` |
| 4 | 按 `P` 拍照、按 `Q` 離開 | 鍵盤操作 |
| 5 | 檢查輸出 | `type runs\<時間戳>\index.jsonl` |
| 6 | 測試 YOLO | `python labs\lab1_detect.py --source data\samples --headless` |

第一節的重點不是飛行，而是把資料流接起來：**鏡頭畫面能進電腦，圖片能存下來，YOLO
能在本機跑起來。**

### 第一節你應該看懂

- 為什麼 `--preview-only` 不需要載入 YOLO
- 為什麼 Tello 連線後不能上網
- `runs\<時間戳>\` 裡的圖片和 `index.jsonl` 是什麼
- 為什麼模型認得瓶子，卻可能認不得鉛筆

## 第二節：Tello 拍照與辨識整合

### 目標

- 從靜態圖片進到連續影像
- 理解 `--every`：每幾幀做一次辨識
- 理解 `--threshold` 與 `--cooldown`：什麼時候自動存檔
- 用 `lab4_patrol.py` 統一處理 image / video / tello
- 說得出即時影像為什麼可以跳過舊幀

### 建議流程

| 順序 | 做什麼 | 指令 |
|---|---|---|
| 1 | 用測試影片跑連續辨識 | `python labs\lab2_loop.py --source data\samples\test.mp4 --every 5 --loop --headless --max-frames 60` |
| 2 | 比較不同 `--every` | `--every 1`、`--every 5`、`--every 20` 各跑一次 |
| 3 | 跑整合版圖片來源 | `python labs\lab4_patrol.py --source image --path data\samples --headless` |
| 4 | 跑整合版影片來源 | `python labs\lab4_patrol.py --source video --path data\samples\test.mp4 --loop --headless --max-frames 50` |
| 5 | 跑整合版 Tello 預覽 | `python labs\lab4_patrol.py --source tello --preview-only` |
| 6 | Tello 畫面加上辨識 | `python labs\lab3_tello.py --every 10` |

第二節的核心問題是：即時畫面一直進來，但模型不一定來得及每一幀都分析。這時候不是把
所有畫面排隊，而是保留最新畫面、跳過舊幀，讓畫面延遲不要越積越長。

### 第二節你應該看懂

- `--every 1`、`--every 5`、`--every 20` 的差別
- 為什麼摘要裡的「跳過幀數」不是 bug
- `--threshold` 和 `--conf` 的差別
- 為什麼冷卻時間可以避免存出一堆幾乎一樣的圖片
- 為什麼 `lab4_patrol.py` 要在啟動時印出「有限來源」或「即時來源」
